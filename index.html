B64Tools

Ferramenta para codificação e decodificação de texto, Base64, GZip e PDF diretamente no navegador.

Use um arquivo PDF para codificar em Base64 ou Base64Gzip.

Como usar

Selecione a operação desejada, insira o conteúdo no campo de entrada e clique em Converter. O resultado aparecerá no painel à direita.

Texto e Base64 (Padrão)

  • Text → Base64: Codifica um texto UTF-8 em uma string Base64 padrão.
  • Base64 → Text: Decodifica uma string Base64 de volta para texto legível (UTF-8).

Variantes de Base64

  • Text → Base64 URL-safe: Codifica o texto substituindo os caracteres + e / por - e _, e remove o preenchimento com =. Ideal para URLs.
  • Base64 URL-safe → Text: Reverte a operação URL-safe para texto original.
  • Base64 → MIME Base64: Formata uma string Base64 em linhas de até 76 caracteres (padrão de e-mails).
  • MIME/PEM → Base64: Remove quebras de linha e cabeçalhos (como -----BEGIN...) de arquivos PEM/MIME, deixando apenas o Base64 puro.

Hexadecimal e Data URI

  • Hex → Base64: Converte uma representação em string hexadecimal para bytes e, em seguida, para Base64.
  • Base64 → Hex: Converte o conteúdo binário do Base64 em uma string hexadecimal legível.
  • Text → Data URI: Cria uma URI de dados completa (ex: data:text/plain;base64,...) a partir do texto.
  • Data URI → Base64: Extrai apenas a parte codificada em Base64 de uma URI de dados fornecida.

Codificações UTF Especiais

  • Text → Base64 UTF-16: Codifica o texto usando a codificação de caracteres UTF-16 antes de converter para Base64.
  • Base64 UTF-16 → Text: Lê os bytes do Base64 interpretando-os como caracteres UTF-16.
  • Text → Base64 UTF-32: Codifica o texto usando a codificação de caracteres UTF-32 antes de converter para Base64.
  • Base64 UTF-32 → Text: Lê os bytes do Base64 interpretando-os como caracteres UTF-32.

Compressão GZip

  • Text → Base64Gzip: Comprime o texto usando o algoritmo GZip e depois codifica o resultado em Base64.
  • Base64Gzip → Text: Decodifica o Base64, descomprime o GZip e retorna o texto original.

Manipulação de Arquivos PDF

  • PDF → Base64: Lê um arquivo PDF do seu computador e o codifica integralmente em Base64.
  • Base64 → PDF: Decodifica uma string Base64 e gera um arquivo PDF para download e pré-visualização.
  • PDF → Base64Gzip: Lê o PDF, comprime seus dados com GZip e gera uma string Base64 otimizada.
  • Base64Gzip → PDF: Decodifica o Base64, descomprime os dados GZip e reconstrói o arquivo PDF original.

Esta ferramenta usa a biblioteca pako para compressão/descompressão GZip em tempo real no navegador. Todo o processamento é feito localmente, garantindo a privacidade dos seus dados.
